# dT-cLmL — Desktop Cloud Mail player

Windows x64 and Linux x86_64 continuation of [cloudmail-player-m0](https://github.com/metravolokos/cloudmail-player-m0). Android is independently maintained in [aN-cLmL](https://github.com/metravolokos/aN-cLmL).

This Flutter application includes read-only Cloud Mail.ru WebDAV, bounded FLAC/MP3 metadata indexing, SQLite library, cover cache and audio playback through MediaKit/libmpv with Windows SMTC and Linux MPRIS.

**History:** source snapshot pinned to `2d373369bfe0e7b256dd98534cc90933336e3811`. Original full Git history was not duplicated because an independent secret scan flagged two historical possible generic API keys. Original commits/PRs/ADRs remain accessible in the source repository.
