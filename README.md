# dT-cLmL — Desktop Cloud Mail Player

Windows x64 and Linux x86_64 development continuation of [cloudmail-player-m0](https://github.com/metravolokos/cloudmail-player-m0).

**Migration staging branch, not release-ready.** Current staging is a partial snapshot of the original source at `2d373369bfe0e7b256dd98534cc90933336e3811`. It does **not** preserve historical commits, and some original files/binary assets are still missing. Do not merge until a complete Git-native transfer or audited equivalent, tests, CI and desktop device smoke tests are done.

Android is developed independently in [aN-cLmL](https://github.com/metravolokos/aN-cLmL). The original source PRs/issues remain at cloudmail-player-m0.

See [migration status](docs/DESKTOP_MIGRATION.md). No project-wide license has been authorized; do not add one automatically.
