# Historical M1 requirement register (superseded scope)

This file records the **original M1-era implementation slice** and intentionally remains historical. It is **not** the complete current teStPlaYclouDE specification or a current feature-status report.

Authoritative complete original user request: [USER_SPEC_RU.md](USER_SPEC_RU.md).

For implemented behavior and outstanding acceptance: [STATUS.md](STATUS.md), [ROADMAP.md](ROADMAP.md), [PLATFORMS.md](PLATFORMS.md). For the reasoning and lineage of changes: [DECISION_INDEX.md](DECISION_INDEX.md) and [DEVELOPMENT_HISTORY.md](DEVELOPMENT_HISTORY.md).

The initial M1 objective was a Russian Flutter Material 3 shell with Tracks, Albums, Artists, Settings, responsive navigation and dark/light/system themes; its Android and Windows UI-launch smoke was accepted in PR #2. Subsequent PR #11 integrated a broader three-platform WebDAV/SQLite/FLAC/MP3/audio-cache preview. The historical M1 acceptance does **not** imply successful remote playback, larger-format support, signed packages or GNOME 51 acceptance.
